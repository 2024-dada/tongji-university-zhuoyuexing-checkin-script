# 同济大学卓越星打卡助手

Windows 桌面助手，将五种卓越星的选择、材料准备、填表、提交和本地查重集中在一个窗口中。

支持 **弘文之星、明德之星、矢志之星、求索之星、力行之星**。通过五个复选框自由组合，也可以点击「全选」。

> 助手会自动提交。请只选择自己实际完成的阅读、学习和活动，核对生成内容及配图是否符合事实。程序不保证适配网站后续的所有界面变化。

## 快速开始

### 1. 下载并完整解压

在本仓库点击 **Code → Download ZIP**，将压缩包完整解压到一个固定文件夹。

双击最外层的 **`启动卓越星助手.cmd`**，打开助手窗口。

仓库附带 Python 运行时，无需另行安装 Python。请保留整个「程序文件」文件夹，不要只复制启动文件，也不要直接在压缩包里运行。

### 2. 在助手中填写 API key

点击 **「填写 / 修改 API key」**，输入自己的 DeepSeek API key，确认保存，直到窗口显示「API key 已配置」。

密钥使用 Windows 本机加密保存。换电脑后请重新填写，不要把自己的密钥、配置或打卡记录发到公开仓库。DeepSeek 调用会产生费用，账户需有可用余额。

### 3. 打开打卡页面

| 使用方式 | 启动前停在哪个页面 |
| --- | --- |
| 企业微信 | 侧边栏「工作台」→「卓越星」→ 完成登录 → 底部加号 → **五种星排列的打卡模块选择页** |
| Microsoft Edge | 登录卓越星，打开同一个 **五项打卡模块选择页**，并勾选助手中的 **「在 Edge 打卡」** |

五项选择页地址：<https://star.tongji.edu.cn/app/pages/index/daka>

矢志之星也从五项选择页进入；当前实现通过 **已登录的 Edge** 处理矢志流程。勾选矢志时，请提前准备好 Edge 登录状态。

### 4. 勾选星项，点击「继续运行」

例如只勾选「弘文之星」和「明德之星」，或点击「全选」。

助手按页面顺序处理勾选项：**弘文 → 明德 → 矢志 → 求索 → 力行**，并根据页面剩余次数运行。操作期间请保持桌面解锁，避免切换、最小化目标窗口或同时使用鼠标键盘。

## 助手会做什么

- 从列表选择未记录的对象，**在进入表单前按名称关键词查重**，减少重复填表和 API 调用。
- 通过 DeepSeek 生成文字，搜索主题相关图片并进行审查，再填写表单、上传图片。
- 弘文之星使用书籍封面；**明德之星无需图片，会跳过搜图和上传**。
- 图片最多审查 50 张；若审满后仍未严格通过，按当前规则采用 DeepSeek 评分最高的候选，并明确提示它是备用图，不代表严格审查通过。
- 支持列表「点击加载更多」。只有明确识别到列表结束且没有未使用对象时，才跳过该星继续其他星；加载无进展或扫描达到上限时暂停。
- 自动提交并识别结果。系统明确提示「已打卡」时，写入 TXT，以后在列表阶段跳过。
- 显示可拖动的置顶进度框，并保存续跑位置。

网络故障、焦点异常或提交结果不明时，助手会暂停。**自动化并不等于每次都能无人值守完成。**

## 常用按钮

| 按钮 | 作用 |
| --- | --- |
| 继续运行 | 启动或恢复任务 |
| 停止（Esc） | 请求停止；正在进行的网络请求可能需要结束后才能停止 |
| 继续当前步骤 | 按提示完成手动步骤后接续执行 |
| 确认已提交 | 仅在你已核实网站实际打卡成功后使用，更新记录并接续下一条 |
| 清空当前页面 | 停止当前操作后清除助手显示；**保留打卡记录、待提交材料、续跑位置、照片和勾选项** |
| 清除运行日志 | 只清除窗口里的日志显示 |
| 查看打卡记录 | 打开本地记录位置 |
| 审核打回 / 移除完成记录 | 查找指定对象，备份后移除对应完成记录 |
| 卸载全部图片 | 删除本地图片和搜图缓存，保留文字记录；待提交图片需要重新准备 |
| 卸载卓越星助手 | 删除程序及其本地数据；请先备份需要保留的内容 |

**遇到「结果待核实」，不要为了继续而盲目确认，也不要重复点击发布。** 先核对网站结果；确已成功时再点击「确认已提交」。

## 打卡记录与更新

每种星分别保存在：

```text
程序文件/
└─ 打卡记录/
   ├─ 弘文之星打卡记录.txt
   ├─ 明德之星打卡记录.txt
   ├─ 矢志之星打卡记录.txt
   ├─ 求索之星打卡记录.txt
   ├─ 力行之星打卡记录.txt
   └─ 续跑记忆.json
```

TXT 是本地查重依据；「续跑记忆」只决定从列表哪里继续找，不能替代 TXT。

- **更新、换文件夹或迁移电脑前，请备份整个「打卡记录」目录。** 不要用分享包里的空记录覆盖自己的记录。
- 没有记录、且网站列表不显示历史状态的对象，程序无法预先知道你以前是否打过；服务器首次提示后才会记住。
- 如需从列表开头重新扫描，可在「更多设置」中清除续跑记忆；这不会删除已完成记录。
- 清空助手页面不会清空历史，无需靠删除记录解决卡住的问题。

## 常见问题

**双击没有窗口？**  
确认已经完整解压，启动文件与「程序文件」在同一层，且 `程序文件/runtime/pythonw.exe` 存在。查看 `程序文件/启动日志.txt` 的具体错误。

**提示 DeepSeek 不可用，但账户有余额？**  
余额充足不代表网络或服务一定正常。查看窗口的具体错误，检查连接、密钥和服务状态后重试；保留现有记录，不必重新解压。

**提示图片域名解析为 198.18.x.x？**  
如果电脑正在使用 Fake-IP DNS 代理，可在「更多设置」勾选「兼容本机代理 Fake-IP DNS」。这是按本机网络情况使用的选项，默认关闭。

**找不到页面、点击位置不正确或上传失败？**  
确认登录未过期、窗口未最小化、所选模式与实际窗口一致。按提示恢复页面后继续。反馈问题时请提供截图和错误日志，并遮住密钥及个人信息。

## 源码与维护

| 路径 | 职责 |
| --- | --- |
| `程序文件/app.py` | 主窗口、星项选择和任务调度 |
| `程序文件/checkin/engine.py` | 常规四星的列表选择与填表流程 |
| `程序文件/checkin/shizhi.py` | 矢志流程 |
| `程序文件/checkin/storage.py` | 各星 TXT 与查重记录 |
| `程序文件/checkin/resume.py` | 续跑位置 |
| `程序文件/checkin/images.py` | 图片筛选与审查 |
| `程序文件/tests/` | 回归测试 |
| `程序文件/tools/build_portable.py` | 分享包构建入口 |

运行测试（在仓库根目录）：

```powershell
cd 程序文件
.\runtime\python.exe -m unittest discover -s tests
```

修改前请阅读 [内部说明](程序文件/README.md) 和 [开发经验](程序文件/agent.md)，以当前源码和最新需求为准。重点保持：**点击前查重、网络故障不误标为已跳过、结果不明不自动重提、清空页面不删除记录**。

本工具通过桌面界面操作，依赖 Windows、企业微信 / Edge、登录状态及网站页面结构；不适用于 macOS、Linux 或手机端。
